# CommentClip - 週刊税務通信 HTMLメールテンプレート生成器

このアプリケーションは、週刊税務通信のHTMLメールテンプレートを生成するためのStreamlitアプリケーションです。コメンテーターのコメントと記事情報から、美しいHTMLメールレイアウトを自動生成します。

## 機能

- 記事情報とコメントを入力してHTMLメールテンプレートを生成
- リアルタイムプレビュー機能
- HTMLファイルのダウンロード機能
- レスポンシブなデザイン
- 日本語フォント対応

## 使用方法

### ローカルで実行する場合

1. リポジトリをクローンします：
```bash
git clone https://github.com/osyoooo/commentclip.git
cd commentclip
```

2. 必要なパッケージをインストールします：
```bash
pip install -r requirements.txt
```

3. Streamlitアプリケーションを起動します：
```bash
streamlit run app.py
```

4. ブラウザが自動的に開き、アプリケーションが表示されます。

### Streamlit Cloud でのデプロイ

1. このリポジトリをフォークまたはクローンします
2. [Streamlit Cloud](https://streamlit.io/cloud) にアクセスします
3. GitHubアカウントでログインします
4. "New app" をクリックして、このリポジトリを選択します
5. メインファイルとして `app.py` を指定します
6. "Deploy" をクリックします

## アプリケーションの使い方

1. **基本設定**: サイドバーで配信日と記事数を設定
2. **記事情報入力**: 各記事の詳細情報を入力
   - 号数: 記事の号数（例: 第3742号）
   - 記事タイトル: 記事のタイトル
   - コメント: コメンテーターのコメント
   - コメンテーター名: コメントした人の名前
   - 名前の頭文字: アイコン表示用の文字（1文字）
   - 所属: コメンテーターの所属
   - 記事リンク: 記事へのリンクURL
3. **生成**: 「HTMLコード生成」ボタンをクリック
4. **確認・保存**: プレビューで確認後、HTMLファイルをダウンロード

## 必要な環境

- Python 3.7以上
- Streamlit 1.25.0以上
